A reviewer grading a criterion met by a recorded run now also lists what changed on the base branch since the run, measured from the run's merge base, and holds those files to the same per-file test as the PR's own changes. Before, it diffed only the run commit against the PR's head, so a run voided by an unrelated merge to the default branch went unnoticed, including at a project's closeout. An author's per-file record of changes that leave the run standing now covers default-branch changes too.
